# SLC Step-Up Jobs — Browser search guide for Claude in Chrome

**What this is.** Instructions for Claude in Chrome. It searches the Salt Lake–area job sites that SLC Step-Up Jobs can't collect by itself, then produces a spreadsheet file that the program imports on its **2 · Add downloaded files** tab.

**How to use it.** Open the Claude side panel in Chrome, attach this file or paste its contents, and add one line such as:

> Run the SLC Step-Up Jobs browser search. Tier A only.

Or narrow it down:

> Run the SLC Step-Up Jobs browser search for hospitals and government only, postings from the last 30 days.

---

## Instructions for Claude

You are collecting job postings for one job seeker in the Salt Lake City area. Work through the sites below in a new tab, gather the postings that fit the profile, and produce the output files described at the end. Work carefully and politely. A smaller, accurate file is better than a large, noisy one.

### The person these jobs are for

- An experienced custodian, 28, who is **extremely reliable** (on time every shift) and wants to move **up and out of hands-on cleaning**.
- Enjoys **crafts** and has an **interest in tech**.
- **Cannot do heavy lifting or climb stairs.** Look for seated, bench-top, or single-floor work.
- No college degree assumed: a high-school diploma, on-the-job training, or a short certificate is fine.
- Lives in the Salt Lake valley: **Salt Lake, Davis, Tooele, and north Utah County (Lehi to Pleasant Grove).** Not Provo, Ogden, or Park City.

### Settings (use these unless the person's message says otherwise)

| Setting | Default |
|---|---|
| Groups | all (see the site tables below) |
| Tiers | Tier A only (see below) |
| Area | Salt Lake, Davis, Tooele and north Utah counties; in-person or hybrid jobs only |
| Posting age | posted within the last **45 days**, and not past its closing date |
| Per site | at most **25** relevant postings, and at most **3 result pages** per search term |
| Search terms | at most **5 terms per site**, chosen from the lists below |

### Rules — always follow these

1. **Read only.** Use each site's own search box or a search URL. Never sign in, create an account, apply, save jobs, message anyone, or submit any form other than a search.
2. **Don't get around blocks.** If a site shows a CAPTCHA, a bot check, a sign-in wall, or an "access denied" page, stop working on that site, record it as **blocked** in the log, and move on. Don't try to solve or bypass it.
3. **Go at a human pace.** Open one page at a time. Don't open dozens of tabs.
4. **Copy what the posting says.** Never guess a pay rate, date, or employer. Leave a cell blank if the posting doesn't state it.
5. **Open each posting** you keep, so you can copy its own URL (not the search-results URL) and read its **Physical Requirements / Working Conditions** section.
6. **Skip duplicates.** Same title + same employer + same city = duplicate. Keep the first one.
7. **Tier B sites** are off-limits unless the person explicitly says "include Tier B". Their terms restrict automated access. If the person includes them, read only the results pages and keep to the per-site limit.

### What counts as relevant

**Good fits — keep these** (seated, bench, or single-floor):

- **Dispatch & scheduling:** dispatcher, service coordinator or scheduler (HVAC, plumbing, pest control, campus operations, transit), patient scheduler, medical support assistant, work-order coordinator, 911 or emergency-communications trainee.
- **Security desk & badging:** access control, badging office, security console or alarm-monitoring operator, GSOC/SOC monitor, lobby or front-desk security. **Not** patrol or roving posts.
- **Purchasing & inventory data (desk):** purchasing assistant/coordinator/clerk, procurement assistant, inventory data entry, inventory analyst.
- **Pre-press & file prep:** prepress technician, production artist, file preparation. **Not** press operator or bindery.
- **Bench engraving & small-format vinyl:** laser engraver, trophy and awards, personalization, decal and sticker production.
- **Embroidery & digitizing:** embroidery machine operator, embroidery digitizer.
- **Dental lab technician:** model room, trimming, scanning, CAD/CAM; trainee roles are ideal.
- **Optical lab / optician assistant:** lens edging, frame adjusting, optical or optometric technician.
- **Electronics assembly & device repair:** electronics assembler, soldering, phone/tablet/laptop repair, bench technician.
- **Library technical services:** library technician, technical services, cataloging, book repair and mending. **Not** library page or shelver.
- **Photo digitization & archival scanning:** digitization or scanning technician, document imaging, metadata technician.
- **Makerspace / FabLab technician:** library or campus makerspaces with desktop 3D printers, vinyl cutters and sewing machines.
- **3D printing operator** and **CAD drafting** (CAD is a stretch goal; keep entry-level or trainee posts).

**Caution — keep only if the ad shows no lifting over 25 lbs, stairs, ladders, long standing, or walking between buildings:**
facilities coordinator or assistant, custodial/EVS **supervisor** (not technician), sterile processing technician, security officer at a fixed desk post, e-commerce product photographer or listing specialist, custom framing.

**Leave out:**
- Hands-on cleaning: custodian, janitor, housekeeper, EVS/environmental services technician or aide, porter, floor tech.
- Physically demanding roles: warehouse, picker/packer, material handler, driver or courier, mover, installer, patrol, library page or shelver, maintenance technician, sign or large-format installer, press operator, visual merchandiser, museum preparator or art handler.
- Inventory, shipping and receiving clerks, leasing agents, inspectors and EHS technicians (these usually involve lifting, stairs or walking properties) unless the ad clearly says the work is at a desk.
- Jobs that need a degree or license the person doesn't have (nurse, engineer, accountant, teacher) and commission-only sales.
- Remote-only jobs and jobs outside the area.

Many desk jobs copy a "lift 50 lbs" line from an HR template. **Still keep a good-fit job** that says this, but copy the physical requirements into the `physical_requirements` column so the person can ask about it.

### Search terms

Pick the terms that fit each site. Add "Salt Lake City, UT" as the location wherever the site has a location box.

- **Desk & operations:** dispatcher · scheduler · service coordinator · patient scheduler · access control · security console · alarm monitoring · purchasing assistant · procurement · work order coordinator · facilities coordinator
- **Bench & craft:** dental lab · optical lab · lens technician · laser engraver · engraving · embroidery · digitizer · electronics assembler · soldering · phone repair · prepress · production artist
- **Library, archive & maker:** library technician · technical services · digitization · scanning technician · document imaging · makerspace · 3D printing
- **Leadership (caution group):** custodial supervisor · environmental services supervisor · building services coordinator

## Output

When you finish, produce **two files**. Use today's date in place of YYYY-MM-DD.

### 1. `slcjobs_browser_YYYY-MM-DD.csv` — the postings

A CSV file (UTF-8, comma-separated, first row = these headers, in this order):

```
job_title,organization,location,salary,url,date_posted,employment_type,site,site_url,track,physical_requirements,summary
```

| Column | What goes in it |
|---|---|
| job_title | The posting's title, as written. |
| organization | The employer. |
| location | City and state as shown, e.g. "Murray, UT". |
| salary | Pay exactly as written (e.g. "$18.50–$21.00 an hour"). Blank if not stated. |
| url | The posting's own link. |
| date_posted | **YYYY-MM-DD.** Blank if not shown. |
| employment_type | Full-time, part-time, PRN, temporary, etc., if stated. |
| site | The site name from the tables above, e.g. "Intermountain Health", "State of Utah jobs", "Local employer search". |
| site_url | The "Where to start" address for that site (for local employer searches, the employer's careers page). |
| track | The best-fitting group from "What counts as relevant", e.g. "Dispatch & scheduling", "Dental lab technician". |
| physical_requirements | The ad's physical requirements **in its own words**, shortened (e.g. "Lift up to 25 lbs; sitting most of the shift"). Blank if the ad has none. |
| summary | 2–5 sentences from the description: duties, schedule or shift, training offered, and the minimum education or certificate (e.g. "High school diploma; CRCST within 18 months"). |

Put every value that contains a comma, quotation mark, or line break inside double quotes, and double any quotation marks inside a value. Remove line breaks inside values.

### 2. `slcjobs_browser_log_YYYY-MM-DD.md` — what was searched

A short log with:
- the settings used (groups, tiers, area, age limit);
- a table: **site · search terms used · postings kept · status** (ok / blocked / nothing relevant / page changed);
- a list of sites to check by hand next time, with the reason.

### Delivering the files

If you can create a download, save both files to the Downloads folder. If you can't, put the CSV in one code block and the log in another, so the person can copy each into a file. For a long CSV, split it across several code blocks that continue one another, and say so.

Finish with a one-paragraph summary: total postings kept, how many per track, how many list physical requirements to ask about, and which sites were blocked.

## After the run (for the person)

1. Save the CSV (for example into the `SLCJobs` folder).
2. Open **SLC Step-Up Jobs → 2 · Add downloaded files**, add the CSV, and click **Score and merge into results**. The program scores each posting with the same rules as everything else (area, career track, physical fit), skips duplicates, and lists anything it leaves out in `SLCJobs_excluded.csv`. Each posting's **site** shows where it was listed.
3. Build the report as usual (it builds automatically if "Build the report when done" is ticked).

The program reads the `physical_requirements` column, so a good-fit job whose ad asks for heavy lifting is kept but marked "check physical section", and a caution job with physical demands is dropped. Postings Claude kept that the program scores as not a fit are dropped at import and listed in the excluded file. That's expected: the program has the final say, so the report stays consistent with the rest of the data.
